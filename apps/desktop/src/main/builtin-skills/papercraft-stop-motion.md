## 适用场景

将科学、教育或知识主题整理成完整的纸艺定格动画科普创作包，产出画风规则、角色与场景设计、资产规划、提示词、分镜结构、动效语言、声音方向、反向提示词和审核标准。适合纸雕、剪纸、立体书和微缩定格讲解：分层纸片、卡纸剪裁、微缩纸雕布景、纸偶定格动作、立体书式展开、纸质道具和真实层间投影。

不适用于：普通二维卡通、线稿涂鸦、真人写实视频或无纸艺质感的标准科普。

当流程从方案/提示词推进到实际视频生成时，本项目视频引擎即 h3.c（MiniMax-H3 本地部署，视频+音频合一），直接用 `engine.submit` 提交，无需选择模型。

## 默认创作目标

除非用户另有说明：

- 目标观众：泛知识用户；目标时长：30 秒短视频
- 画幅：横屏 16:9（`storyboard.materialize` 的 aspect 用 `16:9`；用户指定竖屏/方图时用 `9:16` / `1:1`，预览图与后续视频保持同一比例）
- 交付类型默认完整制作包；用户明确只要某一项时按「轻量请求旁路」执行
- 一个纸艺讲解员加一个核心纸艺模型为默认配置
- 所有视觉资产（预览图、分镜图、镜头片段）落到画布节点，对话区只做简洁指引和决策确认

## 任务流程

1. **读需求**：`document.read` 读需求文档节点或 `canvas.list_nodes` 看画布。分析主题与制作目标，**保留用户原始领域词**，不把科学主题改写成另一个主题。输出需求理解：科普主题、目标观众、目标时长、画幅、交付类型、核心学习目标（观众最后应记住的一句话）、视觉隐喻。缺关键信息用 `ask.user` 补齐，缺省时用上面的默认值。
2. **创意方向**：先总结画风基因（见「全局风格规则」），再提 3–5 个创意方向（每个含标题、核心想法、讲解角度、纸艺视觉隐喻、最适合时长/观众/平台、标志性画面瞬间、风险限制）。展示后必须用 `ask.user` 让用户同时选定创意方向和目标视频时长（15 秒快版 / 30 秒标准版 / 60 秒完整版 / 自定义），未选定时长前不进入详细资产设计。
3. **资产设计**：依次设计纸艺角色（仅当角色能帮助讲解）、纸片场景、分层纸雕布景表、道具资产库（规范见下文各节）；规划或生成 1–3 张视觉预览图（image-gen 节点）确认风格与概念，用户确认视觉方向前不写最终提示词。
4. **分镜表**：`storyboard.plan` 生成分镜表，brief 融入画风基因措辞；只为已选时长出分镜（15 秒约 4 镜、30 秒约 5–6 镜、60 秒约 7–9 镜，每镜只解释一个知识节拍）。用户确认后 `storyboard.materialize` 铺节点（aspect 按确认画幅，tier 先 preview）。
5. **静帧/预览确认**：「需配图=是」的行自动建 image-gen 首帧节点；先提交这些节点请用户在画布查看确认风格与构图，再推进视频。
6. **逐镜提交**：逐镜 `engine.submit` 渲染，**先 preview 档位试跑**，用户确认后提档；不批量闭眼跑。
7. **声音与合成**：按「声音设计」节规划音效与配乐；`timeline.export` 合成导出，核对产物齐全后交付。

每个关键阶段之间都用 `ask.user` 确认（给具体下一步选项，不做开放式追问；推荐项放第一位；用户说「继续」按推荐项处理）。长篇制作方案、分镜、提示词库写入 document/storyboard 节点，不要直接粘贴到聊天区；用户要求修改时优先更新已有节点，不重复建新节点。

### 轻量请求旁路

用户明确只要某一生产资产时，不强制执行完整流程，直接做对应环节，但保留纸艺定格核心画风规则：

- 只要单图提示词：需求理解 → 画风基因 → 单图提示词 → 旁白（如涉及）
- 只要系列图提示词：需求理解 → 画风基因 → 系列图提示词
- 只要 5 秒图生视频提示词：需求理解 → 画风基因 → 图生视频提示词
- 只要分镜：需求理解 → 画风基因 → 分镜 + 节奏 + 运镜 + 转场 + 声音
- 只要创意方向：需求理解 → 画风基因 → 创意方向

## 全局风格规则

### 画面层次（每次方案、提示词和审核都必须强调）

- 场景要有清晰的前景、中景、背景和远景。
- 用纸片叶子、云纹、门框、帘幕、道具或剪影作为前景遮挡，制造空间深度。
- 核心知识对象或主要动作放在易读的中景层。
- 背景不能只是静态平面，要加入背景视差、小型环境动效和层间分离。
- 需要时用圆形、斜向、隧道式、立体书式或剖面式构图帮助观众读出层次。

### 纸艺定格质感（每次方案、提示词和审核都必须强调）

- 所有可见物体都像真实纸材制作：多层卡纸、剪裁边缘、纸纤维、折痕、拼贴缝、标签片、铆钉、关节、拉片、滑轨、转盘和可见厚度。
- 动作像逐帧手工拨动：小幅分段移动、短暂停顿、轻微回弹、铰链动作、滑动纸机关、翻页、拉片揭示和纸片落定。
- 背景元素也尽量是纸艺机关：纸云沿滑轨移动、纸月亮或圆盘沿轨道运动、多层布景视差、纸叶落下、纸灯笼轻晃、纸门打开。
- 避免丝滑 CG 动作、塑料 3D 表面、平面矢量背景、过于静止的背景，以及破坏微缩定格感的大幅角色运动。

### 画风基因（设计前向用户说明的一致性规则）

手工纸艺定格动画感；微缩纸雕场景或剧场箱布景；多层卡纸剪裁可见纸片厚度；哑光可触摸的纸张纹理、纤维、折痕、缝隙、撕边或剪裁边缘；纸偶角色由独立纸片部件叠压组装；层间有真实物理投影；明确的前景/中景/背景/远景多平面结构；微距摄影感、轻微景深和 2.5D 视差；标签、箭头、卡片、图表等教育信息也用纸片制作；背景层也有纸艺机关动效；定格动画动作语言（分段移动、短暂停顿、轻微回弹、铰链关节、拉片、滑轨、转盘、纸片落定）。

理由：纸艺媒介能把抽象科学变成可触摸的模型，天然适合分层讲解；场景必须像真实搭建并逐帧拍摄，而不是只有纸质纹理的普通插画。

### 创意方向推荐类型

1. 立体书旅程：每翻开一页揭示概念的一层
2. 纸艺科学家实验室：纸偶主持人在实验台上演示机制
3. 分层剖面模型：核心对象像剖面图一样打开
4. 微缩自然剧场：生态、地理、天文主题在纸雕景观中展开
5. 纸片机关板：齿轮、箭头、滑轨、标签和移动纸片解释因果关系

### 角色设计

角色可以是主持人、助手、动物向导、拟人化分子、免疫细胞、行星、机器零件或自然力量。每个角色输出：名称和讲解职责；造型语言和比例；纸艺结构（剪纸五官、分层头发或身体、卡纸四肢、关节节点、标签片、铆钉或折叠结构）；表情系统（简单纸片眼睛、眉毛、嘴型、可替换表情卡）；动作方式（定格式小幅移动、铰链手臂、指向、弹跳、滑动或翻卡表情）；系列图一致性所需的可复用身份特征。角色必须简洁到短视频里一眼能读懂。

### 场景与布景

把每个场景当成真实纸艺舞台而非平面背景。每个场景输出：场景名称、科普功能、前景元素、中景主体和动作、背景环境、远景底板或天空、可移动纸艺机关、教育信息承载物（标签、箭头、图表、测量牌、说明卡或标题卡）。尽量使用至少四个空间层，通过间距和投影让核心模型从背景中分离。

分层纸雕布景表必备列：层级编号、平面作用、纸艺元素、材质和边缘处理、动效或视差行为、投影关系、知识表达功能。规则：大多数镜头 4–7 层；阅读量大的标签放稳定层；前景元素可局部遮挡画面增强微缩摄影感；核心概念放注意力最强的中景；用分层解释层级、顺序、结构、因果或尺度。

### 道具资产库

按功能分组：主持人和角色资产；核心科学对象资产；讲解道具（箭头、标签、卡片、图表、放大镜、尺子、仪表）；场景道具（实验台、山丘、书、架子、云、星星、树、水、管道、齿轮）；动效道具（纸条、滑轨、旋转圆盘、立体弹出片、抽拉层、纸屑）；声音提示道具（翻页、剪纸、纸张摩擦、卡扣、弹出、胶带撕拉）。每个资产定义：名称、用途、纸张材质、所在层级、静态或可动、出现时间、一致性注意事项。

### 预览图

写最终提示词或分镜前，基于已确认的创意方向、角色、场景、分层布景规划 1–3 张视觉预览图（image-gen 节点生成，或仅输出说明和提示词）。预览图比例跟随项目视频比例。每张说明：编号和目的、对应哪个已确认创意方向/角色/场景、视觉重点（整体世界观/角色造型/机关清晰度/文化氛围/结尾记忆点）、用户需要判断什么。推荐组合：整体世界预览、机制预览、情绪或结尾预览。展示后用 `ask.user` 暂停确认。

### 提示词规范（提示词用英文撰写）

**单图提示词**必须包含：用户主题和核心对象、纸艺定格动画风格、微缩纸雕舞台、多层卡纸剪裁、可见纸张纤维/折痕/缝隙/剪裁边缘和厚度、层间真实物理投影、微距摄影感和轻微景深，必要时纸质标签、箭头或知识卡片。一张图只传达一个主要概念。

**系列图提示词**每张包含：图号和目的、相比上一张的变化、共享画风锚点、角色和场景一致性锚点、提示词。规则：保持同一纸张材质语言、光源方向、空间层级和角色身份；每张图只解释一个知识步骤；每条提示词保留用户主题中的领域词；除非用户要求变化，系列图保持同一画幅比例。

**5 秒图生视频提示词**包含：保留纸张纹理、剪裁边缘、分层布景和真实投影；缓慢推近、轻微横移或视差运动；纸偶小幅定格式动作；纸质箭头、标签、滑轨或机关轻微移动；前景和背景产生视差；避免光滑 CG 变形、融化、塑料质感或高速镜头。动作要克制，符合纸片物体的物理逻辑。

### 分镜、节奏、运镜、转场

分镜前先给简短内容概述：一句话视频主线、目标时长和比例、主要视觉结构、知识路径（钩子 → 解释 → 例子或文化连接 → 记忆句）。分镜表文字尽量短，必备列：时间、知识节拍、画面动作、纸艺运动、运镜/转场、音效。每镜只解释一个知识节拍。

剪辑节奏：15 秒 4–6 镜每镜 2–4 秒；30 秒 6–8 镜每镜 3–5 秒；60 秒 8–12 镜每镜 4–7 秒；标签卡出现时短暂停顿；观众看懂纸片机关前不要急切；用纸片动作形成节奏，不用强烈数码快切。

运镜（像拍微缩纸艺舞台）：缓慢推近进入纸艺世界；横向平移展示多层视差；固定中景用于主持讲解；微距特写展示纸张纹理和关键道具；轻微俯视展示剖面结构；层间穿梭进入对象内部。避免：高速飞行镜头、360 度大环绕（除非布景专门支持）、数码故障运动、液体融化变形、超写实 CG 镜头行为。

转场（符合纸艺物理逻辑）：翻页、立体书展开、抽拉标签、纸质标签牌遮挡、云朵纸片滑过、圆形纸片遮罩、剪纸门打开、剖面层分开、纸屑飞散、胶带或贴纸揭示。避免电子扫描线、霓虹故障、玻璃破碎、金属擦除和科幻粒子转场（除非用户明确需要反差效果）。

### 声音设计

推荐音效：翻纸声、剪纸声、卡纸滑动声、纸张摩擦声、小木头卡扣声、轻微弹出声、胶带撕拉声、纸偶关节轻响、纸盒打开声、纸屑散落声。音效应来自视频里的真实动作节拍（翻页、纸门打开、纸轨滑动、卡片翻动、纸抽屉拉出、纸盒打开、纸层叠合、轻柔 pop、关节轻响、摩擦），只做触感点缀，不变成夸张卡通音效；最终混音前先把音效映射到分镜时间轴。

配乐方向：BGM 匹配用户主题、文化语境和情绪，不只匹配通用纸艺风。有明确文化属性的主题围绕该主题音乐语言设计（如中秋科普偏清雅国风：古筝、琵琶、竹笛或箫、轻打击、柔和弦乐，并给旁白留白）；无强文化属性的科学或课堂主题可用木琴、马林巴、拨弦、轻打击、温暖教育感。旁白下方保持轻柔，混音时做压低或 ducking。避免厚重电影低频、强烈电音、未来电子质感或过度戏剧化配乐（除非用户要求）。

旁白规则（流程含旁白时）：声音气质匹配主题和观众（亲子/教育用温暖清晰轻柔，课堂/技术讲解可更中性）；对比旁白时长和已选视频时长，偏差超 20% 必须用 `ask.user` 询问压短文案、延展视频还是接受不匹配；检查尾部杂音、点击声、气口残留、突兀截断或模型尾音残留；尾部有杂音优先修复已有音频（裁掉杂音尾部加短淡出），声音表现合适就不要优先重录；需要重录时提示词明确要求结尾干净无尾部杂音，生成后再检查。

### 反向提示词

始终输出简洁反向提示词块保护画风：光滑塑料 3D、高亮 CG 渲染、真人实拍、普通扁平矢量插画、没有纸张纹理的普通卡通、金属科幻表面、玻璃材质、赛博朋克霓虹、数码故障特效、油画笔触、真实毛发或皮肤毛孔、没有纸张纤维、没有剪裁边缘、没有层间投影、边缘过度平滑、高速镜头环绕、融化或液体变形。

## 审核清单

**画风**：能否看到纸张纤维、折痕、缝隙和剪裁边缘？能否看到卡纸厚度？层间是否有真实投影？画面是否像微缩摄影而非平面插画？是否避免了塑料 CG 和真人写实？

**角色**：角色是否像纸偶？五官和表情是否足够剪纸化？关节和四肢是否像分件组装？动作是否保持定格动画的物理感？

**场景**：是否有清楚的前景、中景、背景和远景？道具是否都是纸艺材质并服务讲解？标签、箭头和卡片是否没挡住核心模型？每镜是否只解释一个知识节拍？

**视频**：运镜是否符合微缩摄影逻辑？转场是否符合纸片物理逻辑？音效是否匹配纸张、卡纸和纸偶动作？分镜时长是否匹配目标时长？最后的记忆句是否清楚？

**音频**：旁白时长是否匹配已选视频时长（或已确认解决偏差）？旁白结尾是否干净？BGM 是否匹配主题文化和情绪而非泛纸艺风？BGM 是否在旁白下方不抢讲解信息？纸艺动效音效是否对齐真实画面动作且足够克制？

## 一致性锁定

- 系列图、分镜、视频全链路保持同一纸张材质语言、光源方向、空间层级和角色身份；每条提示词保留用户主题中的领域词。
- 角色卡与场景卡确认后即为权威身份/环境源，下游提示词按相同名称引用；任一资产重做后，下游必须引用最新版本，不静默混用新旧。
- 预览图确认的风格方向锁定后，后续提示词、分镜、视频不得偏离；需变更时用 `ask.user` 确认。
- 关键设定（角色身份特征、场景层级、配色与材质锚点）可 `memory.remember` 记下跨轮复用。

## 红线

- 重跑任一镜（image-gen 或 engine.submit 重提）前必须先 `ask.user` 确认。
- 节点 id 一律 `canvas.list_nodes` 现拉，不凭记忆引用。
- 不静默跳过失败镜头：失败必须告知用户并给出处理选项。
- 每个关键阶段之间必须 `ask.user` 确认再推进；用户未选定创意方向和时长前不做详细资产设计。
