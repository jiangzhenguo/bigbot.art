## 适用场景

将一句口播、一个故事主题、观点句或抽象概念，转化为统一的编辑感纸拼贴动画序列。视觉语言是高级半调纸拼贴：大色块纸面、黑白半调照片剪影、选择性彩色卡纸点缀、暖白描边、柔和纸影、触感定格组装，以及清晰的拼贴音效。

适用于：

- 把一句脚本或观点转成视觉隐喻拼贴动画
- 用拼贴 B-roll 解释简单故事、文学主题或知识点
- 为口播或社交视频制作编辑感纸拼贴动画
- 制作从空色纸背景中逐步组装物件的半调拼贴动画
- 把多条抽象句子或故事节点批量转为独立视觉隐喻动画
- 制作带纸片滑动、弹入、压平、轻响和摩擦声的触感知识短片（不默认加音乐或口播）

不适用于：写实产品广告或真人出镜口播视频；精确可编辑图层、时间线关键帧或透明切片素材；精确 Logo 位置或可读长文字排版；只要提示词不生成媒体。

## 默认创作目标

除非用户另有说明：

- 输出画幅：16:9 横版（`storyboard.materialize` 的 aspect 用 `16:9`）
- 单段时长：每段约 4 秒
- 默认音频：保留或生成触感纸拼贴音效（纸片滑动、弹入、压平轻敲、轻微摩擦、纸片轻响）。本项目视频引擎即 h3.c（MiniMax-H3 本地部署，视频+音频合一），直接用 `engine.submit`，音效随视频一并生成
- 默认不添加 BGM / 旁白口播 / 字幕：可以用 `ask.user` 询问是否需要，但只有用户明确要求时才添加；不要因为「科普/讲解」「社交视频」就自动推断需要人声或音乐
- 视觉风格：高级编辑感半调纸拼贴
- 运动风格：触感停格组装，不使用慢速缩放、泛泛漂浮或平滑数字图层移动
- 图像/视频中文字：避免可读字母、数字、UI、字幕、水印和 Logo
- 图像质量与层次：优先生成好看的 16:9 层次构图，前景/中景/背景清楚，主体层级强，画面丰富但易读，留白可控

## 任务流程

1. **读需求**：`document.read` 读需求文档节点，或 `canvas.list_nodes` 查看画布已有内容。提炼每条句子/概念的核心含义、情绪、动作动词、视觉隐喻、关键物件（3–6 个大而易读的纸片组）、音效含义。缺关键信息（主题、画幅、时长、是否批量、是否要 BGM/旁白/字幕）时用 `ask.user` 补齐。故事主题未指定段落数时拆为 3–6 个简洁节点，各段应有不同隐喻、物件、色场和音效节奏。
2. **制作方案确认（Gate 1）**：先向用户展示简洁制作方案并等确认，确认前不生成任何静帧或视频。方案必须包含：Brief（主题、受众、画幅/时长假设、语气节奏、视觉风格摘要、媒体方案——明确写「默认保留或生成拼贴音效；默认不加 BGM/旁白/字幕」）；每个段落的视觉隐喻（核心含义、情绪、一句话视觉提案、关键物件、背景色与强调色、预计组装顺序、预计拼贴音效点）；脚本/视觉节奏轨（只有用户明确要求旁白才写旁白稿，否则写无旁白视觉节奏轨；只做 B-roll 时保留原句、不发明旁白）。用户只批准部分编号时只推进已批准部分。
3. **生成分镜表**：`storyboard.plan` 生成分镜表，brief 融入本技能的风格措辞（见「全局风格规则」与风格签名）。每段含：段落标题、最终画面描述、动效想法、近似时长、拼贴音效想法、风格连续性与色彩协调说明。
4. **铺节点**：用户确认分镜后 `storyboard.materialize`（aspect 按确认画幅，tier 先 preview）。「需配图=是」的行自动建 image-gen 首帧节点。
5. **静帧确认（Gate 2）**：先提交 image-gen 节点生成各段最终静帧（看起来像未来动画的完成最后一帧），请用户在画布查看确认。静帧太忙、色彩不匹配、纸层过多、边缘太数字化或纸张过旧/过棕时，先修订静帧再生成视频。
6. **逐镜提交视频**：对已批准静帧逐镜 `engine.submit`，**先 preview 档位试跑**，用户在画布确认效果后再提档重提；不批量闭眼跑。失败或漂移按「故障处理」修订 prompt 后重提，重提前先 `ask.user` 确认。
7. **合成导出**：全部镜头批准后 `timeline.export` 合成；若原片段音轨是拼贴音效，默认保留不丢弃。核对产物齐全（各镜片段、静帧、最终视频）后交付，并用一句话说明脚本/视觉节点如何转化为视觉隐喻；批量任务按编号组织结果。

## 音频策略

默认交付是：**带拼贴音效，默认不添加 BGM、旁白口播和字幕**。

1. 第一次制作方案确认时必须写明该默认媒体方式。
2. 旁白/BGM/字幕只能作为可选增强用 `ask.user` 询问，不得作为默认项。
3. 生成视频片段时在 prompt 中要求同步触感拼贴音效：纸片滑动、弹入、压平轻敲、轻微摩擦、小纸片脆响。
4. 最终合成时默认保留原片段拼贴音效；只有用户要求静音、生成音频出现不需要的人声/音乐、或用户要求另行混入音乐/旁白时，才移除或替换音频。
5. 若片段生成后用户才要求 BGM 或旁白，在保留拼贴音效的基础上混入，除非用户要求静音或替换原音效。

## 全局风格规则

对每张静帧和每段视频应用：

1. **统一整体风格**：半调剪影、大色块、暖白描边、柔和实体纸影、干净构图、触感纸材和协调的拼贴音效，整批像同一套编辑感系列。
2. **控制纸张质感强度**：不能像完全扁平数字图层，也不能过旧、脏、皱或偏棕（除非用户明确要求）。优先干净精致的手工纸质感：细纤维、轻微不规则撕边、浅层毛边、层叠接缝和软阴影。
3. **统一色彩基调**：未经确认不引入与静帧或整体色板冲突的牛皮纸、棕色、发黄或做旧底纸。每段从与已确认静帧主色一致的纸面开始。
4. **让运动像停格拼贴**：逐片出现、滑入或弹入、轻微回弹、压平、暂停，然后锁定最终构图。避免快速旋转、过度翻飞、混乱飞散、全局淡入、平滑数字平移/缩放或泛泛漂浮。
5. **保持段落协调**：前一两段建立批次风格和音效节奏后，后续片段和修订参考该节奏与色调。
6. **默认精致 16:9 层次场景**：利用宽画幅建立前景/中景/背景层次、丰富环境道具、清晰主体层级和横向构图，不让画面变碎。
7. **突出纸拼贴工艺**：可分离纸片组、半调照片剪影、彩色卡纸点缀、触感阴影、撕边、层叠接缝，以及弹入、滑入、轻微回弹、压平、暂停、锁定等停格动作必须可见。

### 静帧规格（image-gen 节点 prompt 要素）

每张静帧规格包含：脚本含义/故事节点、视觉隐喻、画幅、背景色场、强调色、关键物件组及作用、构图与前/中/背景层次与留白、最终画面关系、风格连续性说明、避免项。

风格签名（图像 prompt 用英文撰写）：

```text
flat bold color field, black-and-white halftone photographic cut-outs, selective colored cardstock accents, warm cream keylines, soft paper shadows, fine uncoated-paper grain, premium editorial paper collage, clean refined hand-torn paper edges, subtle fibrous edges, layered paper seams
```

色彩建议：

- 焦橙或红色：劳动、时间压力、紧迫感
- 芥末黄：工具、警示、累积错误
- 墨绿：认知、重置、判断、超现实平静
- 深紫：记忆、结构、神秘、梦境逻辑
- 青绿：协作、执行、系统流动
- 玫红：荒诞、仪式、戏剧张力

不要把钴蓝作为自动默认色。通过纸张质感、半调处理、描边、阴影、画幅和受控色板统一整批画面；只有当故事节点需要对比时才变化色场。

静帧硬性要求：扁平大色块纸背景带细微纤维质感；3–6 个大的可分离物件组；主体清楚、层级强、留白干净、前景/中景/背景层次可见；以黑白半调照片剪影为主要结构，场景道具丰富但易读；选择性彩色卡纸仅用于强化层级；暖白描边、柔和实体纸影、精致撕边、轻微层叠纸缝；不出现可读文字、假字母、数字、字幕、UI、水印或 Logo（除非用户明确要求）。

### 停格组装运动方案

默认运动顺序：

1. 从与已批准静帧主背景一致的干净纸色场开始（不是不匹配的牛皮纸或棕色底）。
2. 基础结构作为纸片滑入、弹入或压入。
3. 角色、卡片、物件或主要隐喻元素入场。
4. 次要物件逐个组装，带小幅回弹、压平和暂停。
5. 最终关系锁定到已批准构图。
6. 结尾短暂停留在完整静帧式画面上。

视频 prompt 用英文撰写，模板：

```text
Paper-collage stop-motion assembly. Start on a clean paper field matching the approved still's background color and tone. Assemble the scene piece by piece with tactile stop-motion timing: foreground, midground, and background paper groups appear in a readable order; each paper object appears, slides or pops in, lightly bounces, presses flat, pauses, and locks into place. Preserve the halftone dots, cream keylines, subtle fibrous torn edges, layered paper seams, soft shadows, paper grain, color field, and approved aspect ratio. End by holding the completed composition matching the approved still frame. Sound design: tactile collage SFX only, synchronized to paper-piece motion: soft paper slide, pop-in, press-flat tap, light rustle, and tiny paper snap where appropriate. Default: do not add BGM, voiceover, dialogue, or subtitles unless the user explicitly requested them. No mismatched kraft-paper opening, no brown/yellowed base unless approved, no fast spinning, no chaotic object flight, no smooth digital layer movement, no scene cuts, no camera move, no zoom, no morphing, no new objects, no text, no logos, no watermark, no UI.
```

## 质量检查

逐镜检查静帧和视频：

- 视觉隐喻或故事节点无需屏幕文字也能理解
- 静帧具有漂亮的 16:9 构图、清晰色场、明确物件层级和前景/中景/背景深度
- 物件组数量可读，不是一屏碎片
- 片段从与已批准静帧或批次色板一致的色场开始
- 组装逐片可见，不是整体淡入
- 运动像定格拼贴：独立纸片弹入或滑入、轻微回弹、压平、暂停、锁定
- 默认保留触感拼贴音效；除非用户明确要求，不应有 BGM、旁白口播或字幕
- 纸张质感可控：不太平、不太旧、不偏棕/牛皮纸
- 色调整批一致；最终帧接近已批准静帧
- 没有不需要的可读文字、假 UI、字幕、水印或 Logo

微小细节漂移可接受（隐喻清楚、最终构图仍像已批准静帧即可）。出现严重漂移、文字、假 UI、开场颜色不匹配、未经允许的牛皮纸底、过脏过皱纸质、丢失停格组装、不需要的 BGM 或旁白时，按发生阶段重生成或后期处理。

## 故障处理

- 制作方案默认写成无声视频 → 改为「默认带拼贴音效」，除非用户明确要求静音
- 方案在用户未要求时加入 BGM/旁白/字幕 → 移除并作为可选项询问
- 方案太直白 → 回到 Gate 1，把视觉提案改得更物件化
- 静帧含假文字或 UI → 先重生成静帧，不要只在视频 prompt 里修复
- 静帧或视频太忙 → 减少纸层、简化物件数量、恢复留白
- 视频缺少组装动作 → 减少物件数量，明确逐步到达顺序
- 运动像平滑数字图层 → 围绕停格节拍重写提示：出现 → 轻微回弹 → 压平 → 暂停 → 锁定
- 纸张太平 → 加轻微撕边、纤维、层叠接缝和软阴影
- 纸张过旧或脏 → 去掉牛皮纸、棕黄底、重皱纹、污渍和做旧处理
- 开场颜色与静帧冲突 → 从与静帧主背景一致的颜色开始
- 最终帧偏离静帧太远 → 加强「已批准静帧是完成最终构图」的指令
- 生成音频缺少拼贴音效但画面可用 → 询问用户保留、重生成更强音效方向，或后期补同步音效
- 生成音频出现不需要的 BGM 或旁白 → 交付前移除或重生成
- 用户需要精确图层控制 → 建议改用分层动画或剪辑工作流，不继续本技能

## 一致性锁定

- 已批准的静帧是各段视频的最终构图锚点：视频 prompt 必须引用其背景色、色调、物件组与构图，最终帧必须接近已批准静帧。
- 首批 1–2 段建立的风格、色板与音效节奏是整批基准，后续片段与修订必须对齐。
- 任何静帧重做后，对应视频必须用新静帧的规格重提，不得沿用旧规格；交付与合成不得静默混合新旧版本。
- 角色/物件/色板的关键描述可 `memory.remember` 记下，跨轮保持一致。

## 红线

- 重跑任一镜（image-gen 或 engine.submit 重提）前必须先 `ask.user` 确认。
- 节点 id 一律 `canvas.list_nodes` 现拉，不凭记忆引用。
- 不静默跳过失败镜头：失败必须告知用户并给出处理选项。
- 未获用户确认前不生成静帧或视频（Gate 1 / Gate 2 是硬门）。
- 不默认添加 BGM、旁白口播和字幕；不默认丢弃已生成片段中的拼贴音效。
- 视频逐镜提交，先 preview 档位试跑、用户确认后再提档；不批量闭眼跑。
