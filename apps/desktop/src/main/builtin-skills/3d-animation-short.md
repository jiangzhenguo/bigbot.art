## 适用场景

把一句话故事创意做成完整的故事优先动画短片：项目简报 → 故事大纲 → 角色卡 → 场景卡 → 标准镜头表 → 文本分镜（可选铅笔分镜图）→ 单镜头视频 → 全片拼接与 BGM → 最终复查。适用于需要角色一致、场景连续、节奏明确和音画配合的剧情动画短片、纪念短片、品牌故事与社交媒体内容。

不适用于：单张图片、简单修图、真人写实视频、单一独立镜头、logo 设计、纯提示咨询。

核心规则：**先故事、再资产；所有主要产物按生产顺序落到画布节点；所有需要用户确认的地方用 `ask.user`；视频渲染前必须剥离全部分镜标记**。

## 默认创作目标

除非用户另有说明：

- 视觉基调：温暖风格化 3D 动画（皮克斯感，见「全局风格规则」）
- 画幅与总时长：接收需求后**立即**用 `ask.user` 确认（画幅：16:9 横屏推荐 / 9:16 竖屏 / 1:1 方形 / 自定义；总时长：30–60 秒推荐 / 15–30 秒 / 60–90 秒 / 90–180 秒 / 自定义），两项都确认后才进入下一步，并贯穿用于镜头表、分镜、渲染与合成
- 视频引擎：本项目视频引擎即 h3.c（MiniMax-H3 本地部署，视频+音频合一），直接用 `engine.submit` 提交；先 preview 档位试跑，用户确认后提档
- 台词：有对白、旁白还是无台词由用户指定；只有用户明确指定台词语言时才锁定语言，不默认英文台词
- 交付物按顺序上画布：项目简报 → 故事大纲 → 角色卡 → 场景卡 → 标准镜头表 → 文本分镜文档 → 单镜头片段 → 拼接正片 → BGM 合成成片

## 任务流程

1. **读需求**：`document.read` 读需求文档节点或 `canvas.list_nodes` 看画布。捕捉一句话创意、目标产物、预估时长、画幅、视觉基调、台词需求。缺关键信息用 `ask.user` 补齐；随后立即用 `ask.user` 确认画幅与总时长两个规格。
2. **项目简报**：写入 document 节点（工作标题、一句话 What-if、情绪前提、目标观众感受、主要交付物计划、已确认画幅与时长、台词模式与语言、初始风险）。`ask.user` 确认后继续。
3. **故事大纲**：写入 document 节点（主角 Want/Need/缺陷、核心世界规则、8 拍因果故事骨架、情绪锚点与回收、台词节拍、红线检查）。守门检查：主角是主动的；危机由主角缺陷放大；巧合不能解决问题；结局回收早前情绪锚点；反派压力不是扁平反派；台词揭示关系变化而非解释主题。`ask.user` 确认后继续。
4. **角色卡**：用 image-gen 节点生成带标注的角色参考卡（顺序：主角 → 对比/施压角色 → 可选配角）。每卡含：角色名与定位标注、主 3/4 视角、正/侧/背三视图、表情、材质/服装/道具细节、重要道具标注、提示中重复的「身份锁」、简短视觉 ID 备注（年龄段、身材、发型、服饰色、签名道具、不可改特征）。请用户在画布查看确认后锁定；警告用户：后续修改已锁定角色可能需要重做镜头表、分镜、片段和合成。
5. **场景卡**：image-gen 节点生成无人物场景参考卡（只展示环境，不出现人物、人群、剪影、手、脸或角色客串）。含：主环境总览、关键光态（日景/夜景）、情绪子空间、连续性地标（同场景跨镜头必须保持屏幕位置的固定物体，如厨房中岛、沙发、门框、树、邮筒）、环境重要道具。`ask.user` 确认锁定。
6. **标准镜头表**：`storyboard.plan` 生成六列标准镜头表（规格见「镜头表规格」），brief 融入风格锁措辞。用户批准后跑「镜头表自检门」，六项全过才能进入分镜。
7. **分镜**：用 `ask.user` 选分镜模式——单文本分镜文档（默认，写入 document 节点，规范见「分镜规范」）或文本 + 多宫格铅笔图（可视化模式，铅笔图走 image-gen 节点，仅供人眼审稿）。`storyboard.materialize` 铺节点（aspect 按确认画幅，tier 先 preview）。
8. **逐镜渲染**：分镜批准后逐镜 `engine.submit` 渲染 shot 节点，**先 preview 档位试跑**、用户确认后提档；不批量闭眼跑。渲染规则与失败回退见下文。
9. **合成导出**：全部片段批准后按镜头表顺序 `timeline.export` 拼接；BGM 匹配与混音规则见「质检清单」。核对产物齐全、最终视频无任何分镜痕迹后交付。
10. **最终复查**：用户要求诊断或存在明显风险时，生成简短复盘文本节点，按「质检清单」逐项核对。

## 全局风格规则

除非用户明确指定其他视觉风格，所有角色卡、场景卡、镜头表、分镜、单镜头片段、拼接正片和最终合成都必须使用以下视觉风格锁：

- 渲染风格：皮克斯感 3D 卡通渲染，C4D + Octane 渲染器质感，高级动画电影质量。
- 角色造型：夸张几何概括与极佳材质质感的平衡。不追求 100% 真人解剖结构，使用高概括度几何形体、强剪影和高辨识度设计。
- 比例语言：亲和的风格化比例，可爱或幼态角色采用 2.5–3 头身 Q 版比例，大头小身、体块清晰、轮廓易读。
- 发丝/毛发：整体造型有清晰块面结构，边缘保留精细发丝或绒毛细节；光照下既硬朗有形又有细腻触感。
- 皮肤/材质：温润次表面散射（SSS）质感，耳朵、脸颊、鼻尖、指尖可微红透光；避免生硬塑料感。
- 表演风格：夸张灵动的迪士尼/皮克斯式角色动画表演，运用挤压与伸展，强化眉毛、眼角、瞳孔、嘴唇、脸颊形变。
- 动态风格：高能量态势、清晰动作线、前倾势能、强预备动作、快速但可读的节奏、弹性身体机制和丰富微表情。
- 情绪尺度：可爱与爆发力之间取得平衡；强情绪可以有戏剧性面部变形，但必须保留角色魅力。

负向风格约束：不要写实真人摄影、不要扁平二次元、不要塑料玩具皮肤、不要僵硬人体姿势、不要真实解剖僵硬感、不要无生命表情。

## 镜头表规格

角色卡和场景卡锁定后输出标准镜头信息表（本步强制，不与分镜或视频生成互换）。表格严格按以下六列：

| 镜头编号 & 时长 | 连续性衔接 | 参考锚点（空间+身份） | Hook 类型 | 镜头描述（每秒指令） | 音频与对白轨 |
|---|---|---|---|---|---|

列规则：

- **镜头编号 & 时长**：如 `S03 / 6s`。
- **连续性衔接**：本镜如何自然承接上一镜的结束画面、道具位置、眼神、人物姿态、声桥或情绪状态；以及如何为下一镜开篇铺好钩子。这是跨镜连续性主链。
- **参考锚点（空间+身份）**：四个子字段全部必填——`固定地标`（场景卡确切命名地标及画面相对位置，如 `door-frame: 右侧 1/3`）；`人物位置（机位视角）`（每个角色的画面位置、朝向、初始姿态）；`退场人物状态`（上一镜有而本镜没有的角色，记录离屏位置和原因）；`光位基线`（从场景卡继承的主光/补光/轮廓光方向加本镜调整项）。加上身份绑定：已批准角色卡名和场景卡名（精确）。
- **Hook 类型**：受控词表短标签——`setup` / `visual-joke` / `reversal` / `reveal` / `callback` / `suspense` / `tender` / `chase` / `expression-beat` / `climax`。用于整片 hook 分布自检。
- **镜头描述**：景别、镜头运动、荷兰角设计、表演风格、音效、负向提示，并强制含 `Per-Second Directives` 子节——按秒拆为 `0–1s`、`1–2s` 等指令，亚秒关键节拍用 `2.0–2.5s` 标记。每条每秒指令必须覆盖全部 5 个必填要素：① 动作/姿态/表情（适用时含 squash-and-stretch、anticipation、overshoot、follow-through）；② 镜头运动（推/拉/摇/倾/手持晃动/锁定/环绕）；③ 空间位置（人物在哪、持有什么、地标在画面哪里）；④ 音频线索（旁白/对白/音效/呼吸/沉默，有意静默标 `silent`）；⑤ 与下一秒或下一镜的交接。
- **音频与对白轨**：本镜完整音频脚本，按时间顺序，独立于每秒指令。字段：`旁白`（文本及时间范围，无则省略）；`对白`（台词、说话人、语气、时间范围）；`音效`（关键音效按时间锚定）；`表演备注`（主角离屏旁白标 `narrator-mouth-closed: true`；描述旁白期间表情路径；描述每条对白的眼神和身体动作变化）。

表格全局规则：每镜通过 `连续性衔接` 继承上一镜画面状态并为下一镜铺垫；每秒指令覆盖整镜时长、具体到可直接生成分镜面板，避免「继续移动」式模糊描述；表演必须夸张弹性（迪士尼式 squash-and-stretch、anticipation、overshoot、follow-through、overlap、弧线、快速姿态变化、清晰喜剧剪影）；景别在特写/大特写与其他景别间交替；荷兰角构图必须为追逐、失衡、惊吓或闹剧节拍设计；台词语言仅在用户明确要求时使用；含旁白或对白的镜头每一秒说话时都记录嘴部开合（离屏旁白默认闭、对面对白默认开）；已离屏角色在 `退场人物状态` 至少记录 1 镜，连续 2 镜明确不在场后再移除。

### 镜头表自检门（强制）

进入分镜前对已批准镜头表跑六项硬性自检，任何一项不过必须修订表格并重跑：

1. **Hook 密度**：每镜都有 Hook 类型；每连续 3 镜至少 1 镜用 `reveal`/`reversal`/`callback`；开场镜和收尾镜各带强 hook（`visual-joke`/`reversal`/`reveal`/`suspense`/`tender`）。
2. **单镜时长**：任何镜头不超过 15 秒，节拍需要更长就拆镜。
3. **单镜角色数**：任何镜头不超过 3 个重要角色（有画面动作或对白的角色）。
4. **空间锚点继承**：含 2 镜以上的同场景，下一镜的 `固定地标` 和 `光位基线` 必须与上一镜一致或含明确连续性备注（如 `door-frame 随镜头左环绕由右侧 1/3 移至中央`）。
5. **每秒指令覆盖**：从 `0s` 到镜尾每秒都有每秒指令且含 5 个必填要素；允许亚秒节拍但不能留时间空隙。
6. **跨镜连续性**：逐行读 `连续性衔接` 列必须形成连续链；任何翻转眼神、人物位置、道具状态或光位的镜头必须明确标记翻转（如 `HARD CUT — 时间跳 2h`）。

六项全过后在表格节点顶部加 `shot-table self-check: passed` 戳，再 `ask.user` 申请进入分镜。

## 分镜规范

### 默认路径：单文本分镜文档

整部短片一个 document 节点（命名 `<title> text storyboards`），每镜一节，是渲染的权威参考。文档头部块：项目标题、已确认分辨率/档位、分镜模式、自检状态（如 `shot-table self-check: passed at <时间戳>`）、简短目录（列出每镜 hook 和章节锚点便于跳转）。

每镜章节按顺序包含以下字段：

1. **镜头标题 & 时长** — 如 `S03 / 6s`。
2. **Hook 类型** — 受控词（同镜头表词表）。
3. **场景 & 角色** — 精确场景卡名、精确在屏角色名。
4. **空间锚点卡**（强制四子字段）：`固定地标`、`人物位置（机位视角）`、`退场人物状态`、`光位基线`。
5. **连续性** — `承接 S(N-1)` 一两句交代上一镜结束状态；`交接 S(N+1)` 一句铺好下一镜开场。
6. **双绑定** — `[char:角色名] [scene:场景名] [hook:visual-joke]`，精确角色卡名/场景卡名/hook 类型。**分镜专用参考标记，视频渲染时剥离**。
7. **每面板四象限内容**（按时间顺序，从表格行原样保留）：`时间码`（如 `0–1s`）；`姿态 + 表情`（具体身体姿态、剪影、关键持握、眼神、表情路径，弹性节拍明确写 squash/stretch/anticipation/overshoot——每面板最大块内容，是视频模型读取的视觉节拍）；`镜头`（景别、运动、荷兰角备注）；`音频 + 锚点`（`♪ 旁白: ...` / `对白: ...` / `SFX: ...` / `silent` 加空间锚点备注）；`表演备注`（旁白秒标 `narrator-mouth-closed: true`；对白秒标 `mouth-open: speaker` 并描述表情路径/眼神/身体动作变化）。
8. **布局规则**：3 秒镜 → 3 面板、4 秒 → 4 面板、5 秒 → 5 面板、6 秒 → 6 面板、7 秒及以上 → 每秒 1 面板；亚秒关键节拍按需加迷你面板（仅当该节拍是本镜核心 hook）；面板必须覆盖整镜时长无时间空隙。
9. **每面板绑定**：绑定表格行中精确角色卡（锁外观、脸、发型、身材、服装、签名道具、身份）和精确场景卡（保环境、道具、地标、运动路径、空间逻辑）。
10. **可选 ASCII 布局块（强烈推荐，零成本）**：每面板附小段 ASCII 草图让用户秒扫空间布局，例如：
    ```
    [0-1s]  Mia (L, mid)         door-frame (R)
            ——跪下，双手按苹果筐——
            cam: low push-in, locked
            audio: silent | anchor: basket center-bottom
    ```
    ASCII 仅供参考，视频模型读结构化四象限内容。
11. **分镜专用标记**：关键节拍在时间码后加 `[BEAT]`；需交接特定状态时加 `[HANDOFF → ...]`（如 `[HANDOFF → S04 opening]`）。

每镜章节模板（复制粘贴骨架）：

```markdown
## S03 / 6s — 标题：奶奶把苹果筐递给 Mia

- **Hook 类型**：reveal
- **场景 & 角色**：scene:kitchen | char:Mia, char:Grandma
- **空间锚点卡**：
  - 固定地标：door-frame（右侧 1/3）、kitchen-island（底部居中）
  - 人物位置：Mia（左，中景，面朝镜头）| Grandma（右，前景，面朝 Mia）
  - 退场人物状态：—
  - 光位基线：温暖顶光主光 + 右侧冷反光
- **承接 S02**：奶奶弯下腰从中岛拿起苹果筐
- **交接 S04**：Mia 接住筐转身，门铃响起
- **双绑定**：[char:Mia] [char:Grandma] [scene:kitchen] [hook:reveal]

### 每面板四象限内容

#### 0–1s
- 姿态 + 表情：奶奶弯腰双手持筐；Mia 左侧站姿，眼神好奇
- 镜头：locked medium shot, eye-level
- 音频 + 锚点：silent | Mia: L midground | basket: center bottom
- 表演备注：[BEAT]

#### 1–2s
- 姿态 + 表情：奶奶手臂伸向 Mia，筐倾斜；Mia 双手前伸准备接
- 镜头：locked medium shot, eye-level
- 音频 + 锚点：♪ SFX: basket rustle | anchor: door-frame: 右侧 1/3
- 表演备注：[HANDOFF → S04 opening]
```

### 按镜抽取（重点迭代模式）

用户标记某镜需要重点迭代（通常是 climax/追逐/闹剧节拍）时，把该章节抽取成独立 document 节点（命名 `<title> S05 text storyboard (extracted)`），文档原位置留一行占位（`> S05 — 已抽取到独立节点（见 …）`）。渲染该镜从独立节点读取，其他镜仍从文档读取。用户满意后回填文档（占位换成最新内容），独立节点归档。每个被抽取的镜各自独立成节点，文档用占位追踪。

### Opt-in 路径：多宫格铅笔分镜图（可视化模式）

用户在分镜模式选了可视化模式时，在文本分镜文档之外**额外**为每镜用 image-gen 节点生成一张多宫格铅笔分镜图。文本分镜文档仍是权威渲染参考，铅笔图仅供人眼审稿。

每张铅笔分镜图：右上角强制写双绑定标签（`[char:…] [scene:…] [shot:S03] [dur:6s] [hook:…]`，渲染视频时剥离）；绑定精确角色卡与场景卡；把每秒指令转为分镜面板（4 秒镜通常 4 面板、6 秒镜 6 面板，亚秒关键节拍加迷你面板）。**面板物理排版（强制）**：3 秒镜 → 1×3 条；4 秒 → 2×2；5 秒 → 上排 3 + 下排 2；6 秒 → 2×3；7 秒及以上 → 3 排均衡；每面板占据相同画布面积。**每面板四象限**：左上时间码；右上姿态+表情草图（最大区域）；左下镜头图标+运动箭头加荷兰角小备注；右下音频线索和锚点备注。面板按阅读顺序排布，多个不同镜头不合并到同一图；输出纯黑白铅笔线稿（不上色、不带最终渲染光）；标镜头号，必要时加镜头运动图标、铅笔结构线、动作箭头、时间标记和小注。草稿只是视频渲染参考资产，不是终稿美术。

### 分镜批准与失败回退

全部分镜产出后 `ask.user` 确认：批准分镜并渲染镜头视频（推荐）/ 抽取或回填某镜 / 重画选定铅笔分镜（仅可视化模式）/ 修复角色一致性 / 修复场景逻辑 / 修复镜头标记 / 修复音频锚点标记。

铅笔分镜图质量不达标（布局塌陷、标签糊掉、面板合并、角色走样）时的升级路径：① 用更紧的提示重画同一镜（明确四象限布局、双绑定标签和每面板内容规则）；② 去掉右下音频/锚点象限文字（保留带小 `♪` 标记的空白格）减少文字负载；③ 面板数减 1（合并两秒动作最弱的秒），镜头图标简化为单箭头；④ 同一镜连续 3 次失败后暂停，用 `ask.user` 问用户：该镜切换为色块分镜（灰块占位）/ 放弃该镜铅笔图仅靠文本文档推进 / 回镜头表把该镜拆为两段更短镜头并重跑自检 / 手动提供参考图。默认文本模式没有这套回退——文本分镜失败就直接回镜头表修订该行。

## 单镜头渲染规则

每镜批准后 `engine.submit` 渲染对应 shot 节点。每镜必须严格使用文本分镜文档中匹配章节（已抽取的镜从独立节点取）、角色卡和场景卡。

- 文本分镜文档是权威逐镜参考（叙事、构图、镜头运动、动作编排、每秒时间、镜头号）；铅笔图仅用于人眼侧姿态/剪影预检，不得覆盖文本分镜。
- 角色卡为权威身份源，场景卡为权威环境源。
- **剥离所有分镜双绑定标签**（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`）再渲染；铅笔分镜图的镜头号、镜头图标、箭头和备注也一并移除。
- 渲染片段只含干净的皮克斯感全彩 3D 动画：不要分镜线稿、手绘草图质感、标签、字幕（除非要求）、水印。
- 保持已批准的画幅比例与档位。
- 视频 prompt 用英文撰写。h3.c 强在指令遵循，每秒指令可几乎原文送入；prompt 前缀追加：`Pixar-inspired 3D cartoon rendering, C4D + Octane look, stylized Q-version proportions, warm SSS skin, designed-with-detail hair, strong character design language, clean motion, on-brand color palette`。

### 失败与漂移回退阶梯

某镜渲染失败或漂移时：① 第一次重试：用直接引用表格中 `参考锚点` 块的强化 prompt 重渲染；② 第二次重试：把该镜缩到 ≤6s，砍掉的秒拆成镜头表新相邻行，重跑自检后再渲；③ 第三次重试：放宽要求（去一个道具、简化动作、降低 hook 强度）重渲；④ 同一镜连续 3 次失败：暂停并用 `ask.user` 问用户——继续放宽重试 / 跳过该镜并加 `placeholder: missing clip` 标记供下游复查 / 手动提供参考视频代替生成。

渲染片段与已批准 `参考锚点` 漂移（门框落到错边、人物从错边离屏、光位翻转）时，用引用 `参考锚点` 块的强化提示重渲染；**不要在拼接时静默混合修正版和未修正版**。

## 质检清单

### 拼接与 BGM 规则

- 严格按已批准镜头表顺序拼接（`timeline.export`）。
- BGM 匹配拼接视频的实际节奏、情绪弧、喜剧节拍、追逐节奏和结尾氛围；一条连续 BGM，不逐镜生成。
- 在对白、非语言反应和重要音效下 duck BGM；保留原片段音频和音效（除非用户要求替换）。
- 不加字幕或文字（除非用户明确要求）。
- 最终视频必须干净动画视觉、无任何分镜痕迹，包括没有双绑定标签。

### 最终复查项

- 角色一致性
- 场景连续性（对照 `参考锚点` 列验证：每个地标是否落在表格说的位置）
- 情绪锚点回收
- 镜头意图清晰度
- 对白可懂度
- 音效/动效同步（对照 `音频与对白轨` 列）
- BGM 平衡
- 最终视频无分镜痕迹：没有面板边框、铅笔线、箭头、标签、手写备注、时间标记、姿态残影、分镜文字，也没有双绑定标签（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`）
- 缺失或薄弱片段；任何可能需要重做的资产

## 一致性锁定

用户重做或修订任何产物时，下游步骤必须用最新批准的产物，不能用旧的：

- 角色卡/场景卡重做后，未来的镜头表、分镜文档（含抽取节点、铅笔图）、单镜头片段、拼接、最终合成必须按精确名称引用新卡。
- 镜头表修订后，未来分镜、片段、拼接必须用新表，且自检门必须重跑。
- 分镜文档某章节修订后，对应片段必须用新章节内容；该章节已抽取成独立节点时，独立节点为权威；独立节点修订满意后回填文档并归档。
- 可视化模式下铅笔图重画不强制重渲视频（铅笔图仅供人眼参考）；片段重渲染后，拼接、BGM 和最终合成必须用新片段；BGM 重新生成后最终合成必须用新 BGM。
- 任何重做后：① 在下一条回复中标记重做产物为当前批准版本；② 后续提示优先用新节点；③ 画布存在多版本时按节点名指明当前选用版本再继续；④ 不在最终拼接中静默混合新旧资产。
- 关键设定（角色身份锁、场景地标与光位、已确认画幅/时长/档位）可 `memory.remember` 记下跨轮复用。

## 红线

- 重跑任一镜（image-gen 或 engine.submit 重提）前必须先 `ask.user` 确认。
- 节点 id 一律 `canvas.list_nodes` 现拉，不凭记忆引用。
- 不静默跳过失败镜头：失败必须告知用户并给出处理选项；跳过的镜头必须加 `placeholder: missing clip` 标记。
- 每个用户确认门（画幅/时长、简报、大纲、角色卡、场景卡、镜头表、自检、分镜模式、分镜、片段、合成）必须用 `ask.user`，不用纯对话问题代替；推荐项放第一位，用户说「继续」按推荐项处理。
- 视频逐镜提交，先 preview 档位试跑、用户确认后再提档；不批量闭眼跑。
- 渲染前必须剥离全部分镜标记；最终视频不得残留任何分镜痕迹。
- 镜头表自检门六项不过不进分镜。
