## 适用场景

制作**手绘动画与实拍空间融合**的 15 秒 16:9 单镜创意短片:平面的手绘发光动画出现在真实空间中,0-3 秒内与实拍手或物体明确接触,作为同一个实体连续变形、逃跑,并由慢半拍的手持手机镜头追随。

不适用:精致 CG、恐怖跳吓、毛绒角色、多场景剪辑。

## 默认创作目标

- 一条 15 秒、16:9 的手绘实拍融合成片(单 shot 节点一次生成,本片形态不做多镜头分镜拆分)。
- 固定影像结构必须保留:实拍空间中出现平面手绘发光动画 → 与真实手/物体接触 → 同一实体连续变形并逃跑 → 相机慢半拍追赶。
- 调性:可爱、生活感、怀旧、温柔、略带切感,**不是恐怖喜剧**。
- 环境音由 h3.c 原生音频一并生成(视频+音频合一),在 prompt 末尾写环境音设计。
- 本项目视频引擎即 h3.c(MiniMax-H3 本地部署),直接用 `engine.submit`;**提交给引擎的 prompt 用英文撰写**,但给用户确认的创意稿用用户输入的主语言呈现。

## 连线硬规矩(必须是关联生成)

本技能的成片是 **关联生成(Ref2VA,`mode=ref-image`)**,不是首帧生成。h3 不允许参考图和首/尾帧同时提交(`full references cannot be combined with frame anchors`),混连会被 `canvas.connect` 直接拒绝。

1. 环境、手绘角色、手部都做成图片节点或使用用户图片。节点标题用「环境底图 / 角色卡 / 手部参考」,**不要**把环境图叫「首帧」。
2. 三张图全部 `canvas.connect({ label: "ref-image" })` 连到唯一 shot。对应提示词里的 `<Picture 1/2/3>`。
3. 连完后 `canvas.update_node` 写入 `mode: "ref-image"` 且 `modeOverride: true`,防止被自动切回文生或首帧。
4. **禁止** `label: "first-frame"` 或 `"last-frame"`。环境图只是画面参考,不是帧锚定。
5. `h3.write_prompt` 的 summary 任务类型只写 `[reference generation]`,不要写 `keyframe completion`。

## 任务流程

1. **读需求**:`document.read` / `canvas.list_nodes` 查看需求与画布现状。用户没给场景创意时,缺的关键信息(实拍空间、接触对象或手部动作、情绪氛围、风格限制)用 `ask.user` 一次性补齐。
2. **创意生成**:按「创意发明规则」全新创作一套组合(不复用旧创意),按「输出格式」整理成与用户输入主语言一致的创意稿,先发给用户确认。用户确认前,不提交任何生成。
3. **铺节点**:确认后用 `storyboard.plan` 落一张**只有 1 行**的分镜表——「时长(s)」填 **15**;0-3 / 3-6 / 6-10 / 10-13 / 13-15 五个区间**全部写进该行「画面描述」**,禁止拆成多行多 shot(拆行会让参数变成 4s 短片、文案却仍写 15 秒)。再 `storyboard.materialize`(aspect 16:9)铺出**一个** shot;`canvas.update_node` 确认 `data.seconds=15`。环境、角色、手部若还没有图,先建 `image-gen` 出图给用户在画布上看(标题按「连线硬规矩」,不要叫首帧)。
4. **逐镜生成**:按「连线硬规矩」把环境底图、角色卡、手部参考全部连成 `ref-image` 并锁 `mode=ref-image`。再用 `h3.write_prompt` 把英文版最终 prompt 写入唯一 shot(会按节点 `seconds=15` 约束总时长),`engine.submit` 先 `tier=preview` 试跑;用户在画布确认接触真实感、连续变形、慢半拍追拍和非恐怖手绘质感成立后,再提档(default 等)重跑出成片。不批量闭眼跑。
5. **交付**:单片无需 `timeline.export` 合成时,直接核对 shot 节点产物齐全(15 秒、16:9、有原生音频)即可交付;如用户要求加片头片尾或字幕再进合成。

## 创意理解约束(同语种)

把用户任何语言的输入理解为以下硬性要求,创意稿用用户输入的主语言表达(中文输入用中文、英语用英语、日语用日语;混合输入取主导语言;难判断时用当前对话语言;只有用户要求保留的专名可原样保留):

- 基于参考创意**全新创作**,不表面模仿原句。
- 手绘动画质感必须像蜡笔、粉笔、彩色铅笔、粉彩、粗糙笔刷;线条轻微抖动,有涂抹不均、毛边和逐帧重画感。
- 禁止 3DCG、毛绒玩具感、均匀矢量线、平滑霓虹、恐怖怪物、巨大眼睛、裂口、牙齿、威吓、扑咬、突然黑屏、跳吓。
- 0-3 秒必须出现实拍手与手绘动画的清晰接触:缠住手指、落在掌心、被抓时逃跑、从指尖诞生等。
- 动画作为**同一个实体**连续变形,可在“线条、生物、记号、植物、交通工具、生活小物”等形态间变化,并保留前一形态的痕迹(线、尾巴、色彩拖痕、身体曲线或图案母题);不允许突然出现另一个全新角色。
- 全片在同一空间或相邻范围内连续展开,不剪辑跳到另一地点,像拍摄者真的边走边追。
- 每个区间 0-3、3-6、6-10、10-13、13-15 秒都要有新的变形、移动、接触、发现、恶作剧或惊喜。
- 拍摄者必须参与:伸手、抓、追、打开门或盒子、接住、后退、被恶作剧等。
- 13-15 秒必须有**空间级变形**:之前的线扩散到墙、地板、天花板、窗户、水槽或通道,变成巨大花、星空、夕阳、云、丝带、涂鸦小镇等;结尾要有感动余韵和一点可爱笑点。

## 创意发明规则

每次运行都创建新组合,**不复用**已知参考中的:暗房、电脑、冰箱、星星、爱心、蓝色漩涡、蝴蝶、蛇、章鱼、汉堡、巨大眼睛、牙齿或黑暗结尾。

为以下元素选择新值:① 实拍空间(生活化、可连续追踪的相邻范围);② 手绘实体或初始形态;③ 中心色彩;④ 连续变形链路;⑤ 与真实手/实物的接触方式;⑥ 空间中的追逐路线;⑦ 拍摄者反应;⑧ 最后的空间级变形与可爱笑点。

可用方向:雨天厨房水槽、旧阳台晾衣角、清晨玄关、小书店走廊、火车窗边小桌、浴室镜柜、手作桌、温室通道、自助洗衣店长椅、旧餐桌。只用一个空间或相邻连接区域。

## 创意稿输出格式

中文输入用这个句式开头(其他语言用含义等价的同语种开头,必须含时长、16:9 横版、实拍空间、手绘发光动画融合四个信息):

`15秒,16:9横版视频。将实拍的〇〇与手绘发光动画融合的影像。`

“〇〇”替换为新创作的实拍空间或日常场景。不加标题、舞台设置、色味等辅助小标题,不加解释说明,保持以下段落顺序:

1. 开头句;
2. 实拍空间与手机拍摄质感;
3. 0-3 秒;
4. 3-6 秒;
5. 6-10 秒;
6. 10-13 秒;
7. 13-15 秒;
8. 手绘质感;
9. 相机追随方式;
10. 禁止事项;
11. 环境音。

## Prompt 写作规则

- prompt 可直接用于视频生成,不写成散文。
- 给用户确认的创意稿用其主语言;**提交 `engine.submit` 时翻译为英文**,并逐段保留 11 段结构与全部禁止事项,创意内容不得缩水或即兴改写。
- summary 以 `[reference generation]` 开头,不要写成 `keyframe completion`(那是首帧锚定,和本技能的参考图连线互斥)。
- 0-3 秒必须通过接触让实拍与手绘的融合显而易见。
- 相机不要把动画稳定居中:它慢半拍,在实体已经离开画面边缘后再平移、俯仰或前进。
- 实体必须可追踪:每个新形态都保留上一形态的线、尾巴、色彩拖痕、身体曲线或图案母题。
- 使用柔软、情绪化、可爱漫画节拍:小小踉跄、害羞手势、一个点掉队、花瓣粘到镜头、星星落进掌心、彩纸喷嚏、一个小生物慢半拍落后。
- 避免任何恐怖编码的解剖结构或威胁性动作。
- 不在 prompt 里添加模型参数;引擎参数走 `engine.submit` 的 tier 等字段。

## 交付前检查

用户确认创意稿后生成的视频,逐一核对:

- 接触真实感成立(0-3 秒实拍手/物体与手绘动画明确接触);
- 连续变形成立(同一实体、保留前一形态痕迹、无新角色凭空出现);
- 慢半拍手持追拍成立(不稳定居中、不剪接跳地点);
- 手绘质感成立(蜡笔/粉笔/彩铅粗糙笔触感、非 3DCG、非毛绒);
- 非恐怖调性成立(无跳吓、无威胁性结构);
- 15 秒、16:9、含原生环境音。

## 一致性锁定

- 用户确认的创意稿是唯一事实来源:场景、实体、中心色彩、变形链路、接触方式、追逐路线、空间级结尾,用 `memory.remember` 锁定,重跑时逐字沿用,不即兴换创意。
- 英文提交稿与确认稿语义一致,只做翻译不做二次创作。
- 节点 id 一律 `canvas.list_nodes` 现拉现用,不凭记忆引用。

## 红线

1. **重跑镜头前必须 `ask.user` 确认**(含 preview 提档、失败重提、改 prompt 重跑)。
2. 节点 id 一律 `canvas.list_nodes` 现拉,禁止凭记忆编造节点引用。
3. 不静默跳过失败镜头:失败必须告知用户原因并给出处理方案。
4. 用户明确确认创意稿之前,不提交任何 `engine.submit` / image-gen 生成。
5. 不复用旧创意元素;不引入恐怖编码、3DCG 或毛绒质感,即使用户描述含糊也按本 Skill 调性执行。
6. **禁止首帧 + 参考图混连**。环境图、角色卡、手部参考只能走 `ref-image`;连了 `first-frame` 再连 `ref-image` 会被拒绝,且 h3 无法出片。
