## 6. 文档分段读取(document.read)

**机制**:`chunkText` 纯函数(`packages/shared/src/document.ts`)把 document/storyboard 节点 markdown 切成 ≤ maxChars 的块(默认 4000;空行段落边界优先断块),每块带 1-based 行范围;`document.read` 工具一次返回一块 + 导航提示(共 K 块 / 当前第 i 块 / 下一块怎么读)。

| # | 用例 | 步骤 | 预期 | 自动化 |
|---|---|---|---|---|
| G1 | 短文本 | `chunkText` 少量行 | 1 块,行 1–N,还原全文 | ✅ |
| G2 | 超限断块 | 10 行×100, maxChars=300 | 5 块,行号连续,拼接还原 | ✅ |
| G3 | 段落边界 | 含空行文本,过半遇空行 | 空行并入块尾断块,不截断行 | ✅ |
| G4 | 单行超长 | 无换行 2000 字符 | 1 块,允许超 maxChars | ✅ |
| G5 | 空文本 / 夹取 | 空串;maxChars 越界 | 0 块;上限夹取不报错 | ✅ |
| G6 | 导航提示 | `chunkNav` | 含「共 K 块 / 第 i/K 块 / 行 a–b」 | ✅ |
| G7 | 工具 schema | tool-defs | `document.read` 存在且 nodeId 必填、chunk/size 可选 | ✅ |
