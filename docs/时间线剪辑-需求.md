## 1. 背景与定位

### 1.1 产品边界(PRD 已确认)

- **不做专业 NLE 替代**:裁切 / 转场 / 导出做「基本收尾」即可;
- **保留每个 Take 的内嵌音轨**(h3.c 带声直出),时间线导出时原样保留,不做独立配乐/旁白引擎;
- 时间线是画布工作流的**交付出口**:N 个镜头的 Selected Take 按序入线 → 收尾 → FFmpeg 成片。

### 1.2 双入口职责

| 入口 | 职责 | 编辑能力 | 持久化 |
|---|---|---|---|
| **画布 Inspector**(`TimelineInspector.tsx`) | 编辑**主入口**:编排、参数、导出 | 入线排序 / 选 Take / 裁切 / 转场 / 音量 / 预设 / 导出 | 直接写 `timeline` 节点 `data`(画布快照,自动持久化) |
| **时间线页**(`TimelinePage.tsx`) | **总览 + 交付**:预览、播放头、导出进度 | P0 无(只读快照);P1 支持编辑并**回写**同一节点 | 读节点 data + TakeStore;P1 写回快照 |

**数据单一来源**:`timeline` 节点 `data: TimelineData`。两入口必须读写同一份数据,任何修改以画布快照为准。

### 1.3 核心链路

```
画布:shot 节点生成 Take ──边──▶ timeline 节点(shotNodeIds 自动入线)
                                    │
              TimelineInspector 编排(选 Take / 裁切 / 转场 / 音量 / 预设)
                                    │
                           exportTimeline({sequence, transitions, audio, exportPreset})
                                    │
                    ExportService(ffmpeg)→ ExportTask(进度/产物)──▶ 时间线页轮询展示
```

## 2. 数据模型

### 2.1 `TimelineData`(见 [节点手册.md §3.8](./节点手册.md))

```ts
{
  shotNodeIds: string[];                                // 入线顺序(边派生态自动维护;manualOrder=true 后锁定)
  manualOrder?: boolean;                                // 用户手动排过序 = true(不再被入边重排覆盖)
  picks?: Record<shotNodeId, takeId>;                   // 每个镜头选中的 Take;缺省 = 该 shot currentTakeId
  trim?: Record<shotNodeId, { inSec: number; outSec: number }>;  // 每段裁切入出点(秒);缺省 = 整段
  transitions?: TimelineTransition[];                   // 镜头间转场,长度 = shotNodeIds.length - 1
  audio?: { perClipVolume?: Record<shotNodeId, 0..2>; loudnessNormalize?: boolean }; // 缺省 loudnessNormalize=true
  exportPreset?: { format?: 'mp4-h264'|'prores'; resolution?: '1920x1080'|'1280x720'|'source'; platforms?: Array<'9:16'|'1:1'|'no-subtitle'> };
}

interface TimelineTransition { afterIndex: number; kind: 'cut'|'crossfade'|'fade-black'; durationMs?: number; }
```

### 2.2 字段语义与默认值

| 字段 | 缺省 | 说明 |
|---|---|---|
| `shotNodeIds` | `[]` | 由入边派生态追加(边序去重);`manualOrder=true` 后仅用户操作改它 |
| `picks` | 各 shot 最新成功 Take | 缺省跟随 shot 节点 `currentTakeId` |
| `trim` | 整段 | `inSec/outSec` 秒;导出端 `-ss/-to` 精确裁切 |
| `transitions` | 全部 `cut` | `cut` 无时长;`crossfade/fade-black` 用 `durationMs`(默认 500) |
| `audio.loudnessNormalize` | `true` | −14 LUFS(loudnorm),节点级开关 |
| `audio.perClipVolume` | `1` | 0~2,超范围 clamp |
| `exportPreset.format` | `mp4-h264` | `prores` = ProRes 422 + PCM |
| `exportPreset.resolution` | `source` | 不缩放 |
| `exportPreset.platforms` | `[]` | P2 衍生版本(P1 仅记录) |

### 2.3 派生关系(不是持久化字段)

- `shotNodeIds` ← 入边(`clip`/`audio-track`/`sequence` 端口)自动维护;
- 「就绪状态」← 对每个 shotId 查 `takesHistory`:存在 `status==='succeeded' && resultPath` 才算就绪;
- 「片段时长」← 优先 `picks` 对应 Take 的 `durationSec`;其次导出探测;缺省展示 8s 兜底(演示态)。

### 3.2 P1 增量需求(核心缺口,待实现 🔴)

> 全部围绕一个目标:**时间线页从「只读预览」升级为「可编辑工作台」,且两入口双向同步**。

**F1 — Take 拖拽入线 / 换片**
- 需求:Take 池条目可**拖入**视频轨;池内条目可拖到**任意槽位替换**该镜头当前 Take(写 `picks[shotId]=takeId`);
- 轨道片段可**拖动改序**(重排 `shotNodeIds` + `manualOrder=true`);
- 验收:拖动后画布 Inspector 立即看到新顺序/新 Take;松手失败(拖到不可放位置)不改变任何数据。
- 交互实现:HTML5 DnD 或 pointer 拖拽(与「+」拖拽连线同一套基础设施),不做第三方依赖。

**F2 — 时间线页编辑回写画布节点(双向同步)**
- 需求:时间线页对 `picks / trim / transitions / audio / exportPreset / shotNodeIds(顺序)` 的任何修改,**实时写回**对应 timeline 节点 `data`;
- 机制:`saveCanvasSnapshot`(或现有防抖保存)把节点 data 更新写回项目画布;页面与画布共享同一 `CanvasSnapshot` 渲染结果;
- 反向:画布 Inspector 修改后,重新进入时间线页(或 tab 激活时)自动刷新;
- 验收:时间线页改 Take → 回画布选中 timeline 节点 → Inspector 显示同一 Take;无需手动刷新。

**F3 — 顶部工具按钮接真实功能**
- 需求:时间线页顶部「裁切 / 转场 / 响度统一」三个按钮从**摆设**变为**行为入口**:
  - **裁切**:选中片段(或当前播放头片段)→ 弹出该段 in/out 输入(或双滑条)→ 写 `trim[shotId]`;
  - **转场**:打开转场编辑条(在轨道片段之间的转场标记上点按 → 改 kind/毫秒)→ 写 `transitions`;
  - **响度统一**:切换 `audio.loudnessNormalize`,显示当前 -14 LUFS 状态;
- 验收:三按钮都有可见交互;改完立即反映到轨道视觉与导出参数。

**F4 — 导出选项接入真实导出并回写**
- 需求:右侧「格式 / 分辨率 / 多平台」chips 从本地假 state 改为读写 `exportPreset`(与 Inspector 同源),`startExport` 必须使用它们;
- 验收:右侧选 ProRes → 导出命令走 prores 编码;选 1280×720 → 带 scale;选完回画布 Inspector 看到相同预设。

**F5 — 项目上下文**
- 需求:时间线页不再硬取 `listProjects()[0]`,改为接收当前 `projectId`(由 App 导航时传入;画布打开的即是当前项目);
- 验收:多项目环境下,时间线页展示**当前项目**的 timeline 节点与 Take。

**F6 — 真实数据渲染 + 显式空态(去演示假数据)**
- 需求:
  - 轨道**转场图标**由 `tlData.transitions` 渲染(数量/位置/类型一致),不再用写死 `TRANSITIONS`;
  - **连续性轨**由真实数据派生(相邻镜头的尾帧→首帧校验结果;无数据时整行空态,不显示演示文案);
  - **音频轨**:有真实 Take 时用其波形/音量条,无则显示空态「无音轨数据」;`perClipVolume` 在片段上可视;
  - 无任何真实产物时:页面显示**引导空态**("先在画布生成镜头并连线入线" + 去画布按钮),不再展示 5 槽设计稿假片段;
  - 标题「草原之河 · 时间线」改为「`{project.name}` · 时间线」;信息条由真实片段数/总时长计算;
- 验收:空项目打开时间线页 = 干净引导页;有产物 = 全轨道真实数据,无一处写死文案。

## 4. 交互规格

### 4.1 画布 Inspector(`TimelineInspector.tsx`,现状,稳定)

自上而下:

1. **入线镜头序列** — 每镜头一行:
   - 缩略图(当前 Take 产物首帧;无 → 「待生成」占位)
   - `#N 标题`、可用 Take 计数
   - 控制:↑ ↓ ×(P1:整行可拖动改序)
   - 副行:Take 下拉 / in→out 裁切 / vol
2. **镜头间转场**(N≥2 时)— N-1 行:`#i→#i+1` + kind 芯片 + ms 输入;fade-black 附 P0 限制提示
3. **音轨** — 响度统一开关(chip 高亮即开)
4. **导出预设** — 格式 / 分辨率 / 多平台 chips
5. **KV 元数据** — 总片段 / 就绪片段 / 音轨摘要 / 导出格式
6. **动作** — `导出 MP4`(禁用态:无项目/无条件);`打开时间线页面`

### 4.2 时间线页(`TimelinePage.tsx`,P1 目标态)

```
┌────────────────────────────────────────────────────────────┐
│ topbar: ← {项目名} · 时间线   筛选说明    {真实片段/时长}   │
├───────────────────────────────┬────────────────────────────┤
│ 监视器(当前片段/播放头)        │ 导出面板:                  │
│ 播放头控制(上一段/播放/下一段) │  格式/分辨率/多平台 chips   │
│ Take 池(拖拽入线/换片)         │  导出按钮 + 进度条/阶段    │
├───────────────────────────────┴────────────────────────────┤
│ 工具条: 裁切 │ 转场 │ 响度统一                   00:00─▶46 │
│ 标尺(点击/拖动定位播放头)                                  │
│ 视频轨: [片段1][转场][片段2][转场]…(缩略图+角标 Take·时长)  │
│ 音频轨: 波形条(真实派生)+ 音量标识                          │
│ 连续性: 尾帧→首帧 ✓ / ⚠ 建议重跑 / 空                       │
└────────────────────────────────────────────────────────────┘
```

**行为规格**:

| 交互 | 行为 |
|---|---|
| 点击片段 | 监视器显示该片段(缩略图/时间码);选中态高亮 |
| 播放/上一段/下一段 | P1 仅定位播放头 + 切换监视器(P2 若接真实视频预览再扩展) |
| 标尺点击/拖动 | 播放头定位(现有,保真) |
| Take 池拖到轨道片段 | 写 `picks[shotId]=takeId`;监视器/角标/缩略图同步(F1) |
| 片段拖动改序 | 重排 `shotNodeIds`,`manualOrder=true`;边不动(F1) |
| 裁切按钮 | 选中片段 in/out 面板 → 写 `trim`(F3) |
| 转场按钮 | 转场编辑条 → 写 `transitions`(F3) |
| 响度按钮 | 切 `loudnessNormalize`(F3) |
| 导出 | 读 `tlData`(sequence/transitions/audio/exportPreset)→ 轮询进度(F4) |
| 空项目 | 引导空态:「先在画布生成镜头并连线入线」+ 去画布按钮(F6) |

### 4.3 空态 / 错误态

| 场景 | 表现 |
|---|---|
| 项目无 timeline 节点 | 引导:提示在画布添加时间线节点(不展示演示假片段) |
| shotNodeIds 非空但无成功 Take | 占位片段「镜头 N · 待生成」,导出禁用并提示 |
| 导出失败 | notebox 展示 ffmpeg 尾部错误,停留在可重试状态 |
| 导出中再次点击 | 禁用按钮,「导出中…」 |
| 已有完全相同的边(画布「+」拖拽) | toast「已存在相同连线」,不重复入线 |

## 5. 主进程导出规格(`ExportService`,现状基线)

### 5.1 两条路径

| 路径 | 触发 | 行为 |
|---|---|---|
| 简化 `clips[]` | 老接口/无 timeline 编排 | concat demuxer 顺序拼接 + 统一编码 |
| 编排 `sequence[]` | 填了 sequence | filtergraph:trim / volume / xfade / loudnorm / 编码 / 分辨率 |

### 5.2 能力矩阵

| 能力 | 参数 | 实现 |
|---|---|---|
| 入出点裁切 | `sequence[].trim.inSec/outSec` | `-ss/-to` + filter `trim` |
| 每段音量 | `sequence[].volume` / `audio.perClipVolume` | `volume=` filter |
| 响度统一 | `audio.loudnessNormalize=true` | `loudnorm=I=-14:TP=-1.5:LRA=11` |
| 叠化转场 | 整段同种 `crossfade` | `xfade=transition=fade` + `acrossfade` 链式 |
| 黑场转场 | `fade-black` | P0 等价硬切(P2 补 overlay) |
| 硬切/混用 | 其余 | concat filter |
| 编码 | `format=mp4-h264` | libx264 + yuv420p + aac 160k + faststart |
| ProRes | `format=prores` | prores_ks profile 2 + yuv422p10le + pcm_s16le |
| 分辨率 | `resolution≠source` | `scale=w:h`(视频 filter;注意与 -vf 不冲突) |
| 进度 | — | `-progress pipe:1` → out_time_ms/duration → 0~99% |

### 5.3 约束与校验

- 路径白名单(assets/outputs/exports/imports 根);片段不存在 → 报错;
- 编排路径每镜头必须能解析到 `resultPath`(TakeStore),否则拒绝并指出镜头;
- 单任务串行(先来先跑),子进程结束释放;
- 输出 `EXPORT_DIR/<safeName>-<id>.mp4`,名字清洗防穿越。

| 项 | 要求 |
|---|---|
| 向后兼容 | 旧快照只有 `shotNodeIds` → 零迁移;老 `clips[]` 导出行为不变 |
