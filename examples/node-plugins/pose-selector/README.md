# pose-selector 示例插件（受控 UI · 可视化选择器）

演示节点插件如何用 **manifest 里的 `ui` 声明** 让宿主渲染一个可视化选择器：
缩略图网格 + 搜索 + 体系/分类筛选 + 视角分组 + 选中预览，选中后写回 `pose` 与 `angle` 两个参数。

- 插件 id：`bigbotart-pose-demo`
- 节点局部 kind：`pose-selector`（注册后完整 kind 为 `plugin:bigbotart-pose-demo:pose-selector`）
- 参数：`pose`（姿势 id）、`angle`（视角），都由选择器写入
- 清单：`catalog/poses.json`（缩略图相对清单文件目录：`thumbs/*.png`）

## 安装与运行

1. 在 BigBotArt「设置 → 节点插件」安装本文件夹。
2. 画布上添加「姿势选择」节点。
3. 检查器里出现姿势选择器：上方是搜索与「人体/动物」「站姿/动姿/坐姿」筛选，中间是缩略图网格，
   网格下方是「正面/侧面/背面」视角切换，下方是选中预览。
4. 点一个缩略图 → `pose` 与 `angle` 写回节点参数。
5. 点「运行插件」→ 生成该姿势的参考图 PNG 与一条 Take。

## 边界

- 插件**不提供** UI 代码：网格、搜索、筛选、预览全部由宿主用通用组件渲染（`plugin-picker`）。
- 插件只提供清单数据与图片文件；图片通过只读协议 `bba-plugin://<pluginId>/<version>/<相对路径>` 提供，
  宿主只放行插件目录内的图片后缀（png/jpg/jpeg/webp/gif）。
- 清单文件缺失时插件会被判定为不可运行；清单内容非法时选择器会显示明确错误，而不是空白列表。
- 缩略图是示例用的占位图，替换成真实姿势图即可用于实际项目。
